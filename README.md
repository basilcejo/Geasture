# Gesture Hero - Animated Superman

A webcam-controlled Pygame game using MediaPipe hand tracking.

## Controls
- Open hand: move Superman vertically
- Fist: activate laser
- R: restart after Game Over
- ESC: quit

## Folder structure
```text
Gesture_Hero_Animated/
├── main.py
├── requirements.txt
└── assets/
    └── superman.png
```

## Install
```bash
pip install -r requirements.txt
```

## Run
```bash
python main.py
```
